🚀 Employee Management System (Java)

This is a console-based Java application that allows users to manage employee records efficiently using core Java concepts like OOP, Collections (HashSet), and User Input handling.

✨ Features

🔹 Add new employees
🔹 View employee details by ID
🔹 View all employees
🔹 Update employee information
🔹 Delete employee records
🔹 Menu-driven console interface

🛠️ Technologies Used
Java
OOP (Encapsulation, Classes, Objects)
Collections Framework (HashSet)
Scanner (User Input)
